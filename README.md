# 🍕 Pizza Ordering System (Windows Forms - C#)

A real-world inspired Pizza Ordering Desktop Application built using **C# Windows Forms**.  
It simulates a complete ordering experience from selecting items to generating a final bill across multiple interactive forms.

---

## 🎯 Project Overview

This application allows users to go through a full pizza ordering workflow in a structured and interactive way:

- Start a new order from a Welcome screen  
- Customize pizza type, size, and extra additions  
- Choose dining option (Eat In / Take Away)  
- Review complete order details  
- View final price calculation  

The system is built using **event-driven programming** and demonstrates real desktop application flow using Windows Forms.

---

## 🖥️ Application Flow

The project consists of 3 main forms:

### 1️⃣ Welcome Form
- Entry point of the application  
- Displays welcome message  
- Contains **Start Order** button  
- Navigates to Order Form  

---

### 2️⃣ Order Form
Handles all user selections:

- Choose pizza type  
- Select pizza size  
- Add extra toppings or options  
- Choose dining option using Radio Buttons  
- Uses Buttons, Labels, and Radio Buttons for interaction  
- Proceed to order summary  

---

### 3️⃣ Order Summary Form
- Displays full order details  
- Shows final calculated price  
- Allows user to:
  - Confirm order  
  - Start a new order (returns to Welcome Form)
